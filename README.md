# 🖥️ Computer Vision Trainings (2025)  
*A series of webinar-based trainings by Yandex, with implemented homework assignments.*

## 📌 Overview  
This repository contains my solutions to homework assignments from the **Yandex Machine Learning Trainings Season 3** (2025). Each webinar focused on a key CV topic, followed by a practical coding task.  

## 📚 Official Training Materials  
All webinar lectures, slides, and datasets are publicly hosted by Yandex.  

- 🔗 [Main Training Portal](https://yandex.ru/yaintern/training/ml-training)  
- 📂 [Slides/Code Repo](https://github.com/girafe-ai/ml-course/tree/25s_ml_trainings_3)  

## 🗂️ Webinar Topics  
1. **Convolutions**  
   - Homework: Image Classification (MNIST, FashionMNIST) 
2. **Classic Computer Vision Methods**  
   - Homework: NumPy implementation of Edge Detection algorithm with Sobel Filters
3. **Image Local Descriptors**  
    - Homework: OpenCV implementation of SIFT algorithm
4. **Overfitting and Normalization**
    - Homework: Neural Net overfitting and Normalization

## 🛠️ Technologies Used  
- Python, OpenCV, PyTorch
- Libraries: NumPy, Matplotlib
